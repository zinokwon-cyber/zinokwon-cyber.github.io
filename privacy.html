Privacy Policy

Korea Decoded Uploader. Effective date: November 5, 2026.

What this app is

Korea Decoded Uploader is a private tool operated by the owner of the Korea Decoded YouTube channel. It uploads videos made by the owner to the owner's own YouTube channel. It is not offered to the public.

Google data accessed

  • Scope used: https://www.googleapis.com/auth/youtube.upload
  • The app uses this permission only to upload videos and thumbnails to the authorizing account's own channel.
  • The app does not read, collect or store viewer data, comments, contacts, email or any other Google user data.

Storage and security

The OAuth token is stored as an encrypted secret in the owner's private GitHub repository and used only by the owner's automated build. It is never sold, shared or transferred to third parties.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
